# web-harness
Web Harness: interface web de chat com LLMs (OpenAI-compatible) com relay CORS, orquestração de agentes/sub-agentes/skills, ferramentas MCP (workspace, Weditor, Wcalc, Wcurl), visão multimodal por imagem e autenticação backend (usuário/senha). Tudo no navegador, com sessão protegida no servidor.
